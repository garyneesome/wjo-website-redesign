## Deliberately unresolved

**Wollaston Village Hall, 52 High Street, Wollaston, NN29 7QQ** remains on the WJO crest fallback. Search results repeatedly surfaced the separate Wollaston Village Hall near Stourbridge. V67 does not use an unverified photograph.

## Address discrepancies noticed during source checking

These are recorded for review only and are **not changed in V67**:

- Paddox Primary School official sources use **CV22 5HS**; WJO data currently uses CV22 5JH.
- Arncott Parish Council lists **Greenfields, Upper Arncott, OX25 1QP**; WJO data currently uses Murcott Road, OX25 1QH.
- Houlton's official page lists **The Barn, Dollman Farm, Dollman Road, CV23 1EP**; WJO data currently uses CV23 1AL.
