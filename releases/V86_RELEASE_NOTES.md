# WJO V86 — Homepage refresh

**Built on V85.** This release changes the homepage only and retains the approved Jado imagery and existing site functionality.

## Design changes
- New photographic, dark-ink introductory hero with a single dominant class-finder action and optional first-visit help.
- Smaller, balanced headline with no conspicuous programmed-focus border.
- Three aligned, photographic programme links for Super J's, Confident Kidz and Teens & Adults.
- Cleaner family-story section with one meaningful image and three concise support points instead of staggered photo tiles.
- Distinctive belt-progression motif and link to existing grading information.
- Clear three-step first-visit journey and useful instructor, student-code and safeguarding links.
- Mobile-first cards, typography, whitespace and reduced sticky-navigation footprint.
- Uses the existing owner-approved Jado photo assets — no newly generated martial arts or uniform imagery.

## Preserved
- V85 Brown Belt 2nd Tag reference resources and download images.
- Existing 12 grading resources and RACHEL Student Code.
- Original Committee Hub and front-end admin routes.
- Guided school finder, venues, full news import, safeguarding, events, shop, existing footer and mobile menu.

## Build / QA
- Validates V86 JavaScript syntax, section counts, navigation destinations and mobile CSS breakpoints.
- Rebuilds the full single-file demo and ZIP and verifies critical earlier content remains in the output.
- The screenshot appearance has not yet been independently visually approved on the user's Android device; use the V86 ZIP for testing.
